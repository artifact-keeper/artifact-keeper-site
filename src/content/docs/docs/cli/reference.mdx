## `ak auth`

Authenticate with an Artifact Keeper instance

```
Usage: ak auth [OPTIONS] <COMMAND>
```

### `ak auth login`

Log in to an Artifact Keeper instance

```
Usage: ak auth login [OPTIONS] [URL]

Arguments:
  [URL]  Instance URL (uses default instance if omitted)

Options:
      --token                Skip interactive prompt and go straight to token authentication
      --oidc-device          Sign in with the RFC 8628 device authorization grant instead of
                             prompting for a password or token. Prints a verification URL and a
                             short user code, then polls until the user approves it. Works
                             headlessly and with SSO-backed instances. Requires backend 1.12.0+
                             [alias: --device]
      --scope <SCOPE>        AK scopes to request with --oidc-device (repeatable, or
                             comma-separated). Defaults to `read:artifacts`
```

```
Usage: ak repo update [OPTIONS] <KEY>

Arguments:
  <KEY>  Repository key

Options:
      --new-key <NEW_KEY>
          New repository key (rename the URL slug)
      --name <NAME>
          Display name
      --description <DESCRIPTION>

      --allow-anonymous <ALLOW_ANONYMOUS>
          Allow anonymous (unauthenticated) downloads (true/false) [possible values: true, false]

      --index-upstream-url <INDEX_UPSTREAM_URL>
          Cargo index upstream URL (remote repos)
      --pypi-upstream-index-path <PYPI_UPSTREAM_INDEX_PATH>
          PyPI simple-index prefix ("" for flat CDN, "simple" for PEP 503 default)
      --release-repository-key <RELEASE_REPOSITORY_KEY>
```

### `ak artifact push`

Upload an artifact to a repository

```
Usage: ak artifact push [OPTIONS] <REPO> <FILES>...

Arguments:
  <REPO>      Repository key
  <FILES>...  File(s) to upload (supports glob patterns)

Options:
      --path <PATH>                  Target path within the repository
      --chunk-size <CHUNK_SIZE>      Chunk size for large file uploads (e.g. "8MB", "16MB")
                                     [default: 8MB]
      --no-chunked                   Disable chunked upload (force single PUT even for large files)
      --content-type <content_type>  Override the Content-Type sent to the server (e.g.
                                     "application/x-rpm"). When omitted, the type is detected from
                                     the file extension, falling back to "application/octet-stream"
```

## `ak api`

Send any HTTP request to the instance, with its auth and TLS settings

```
Usage: ak api [OPTIONS] <METHOD> <PATH>

Arguments:
  <METHOD>  HTTP method: GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, or any other
  <PATH>    Path on the instance, or an absolute URL

Options:
  -H, --header <HEADER>        Request header as 'Name: value' (repeatable)
  -Q, --query <KEY=VALUE>      Query parameter as key=value, URL-encoded for you (repeatable)
      --body <JSON>            JSON body: the text itself, @file, or @- for stdin
      --raw-body <DATA>        Raw body, streamed: @file, @- for stdin, or the text itself.
                               Content-Type defaults to application/octet-stream
      --form <FIELD>           Multipart field (repeatable): key=value, or key=@file with optional
                               ;type=<mime> and ;filename=<name>. Start a value with \@ for a
                               literal @
      --urlencode <KEY=VALUE>  URL-encoded form field as key=value (repeatable)
  -o, --output <FILE>          Write the response body to a file, or - for stdout, as it arrives
  -i, --include                Print the status and response headers before the body
      --head-only              Print the status and response headers, and no body
      --no-follow              Don't follow redirects. Prints the Location to stderr
      --fail                   On a failure status, print only the status and exit 22, like curl -f
      --no-fail                Exit 0 whatever the status, with the body sent as usual, like plain
                               curl
      --url <URL>              Use this base URL instead of the instance's, such as the metrics port
      --anon                   Send no credentials
      --max-time <SECONDS>     Give up after this many seconds. By default only connecting has a
                               limit
```
