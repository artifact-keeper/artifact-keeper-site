Only the latest release is supported. Upstream's [SECURITY.md](https://github.com/artifact-keeper/artifact-keeper/blob/main/SECURITY.md) lists:

| Version | Supported |
|---------|-----------|
| `main` (development) | Yes |
| Latest release tag | Yes |
| Older releases | No |

The current release is **v1.11.10** (2026-10-29). Fixes, including security fixes, ship as new releases on the latest line; older lines do not receive backports. Keep your instance on the latest release.

## Cadence

Minor releases have shipped every few weeks in 2026, with patch releases in between as fixes land. See [GitHub releases](https://github.com/artifact-keeper/artifact-keeper/releases) for the full history.

## Reporting security issues

Do not report security issues as public GitHub issues. Use [GitHub private vulnerability reporting](https://github.com/artifact-keeper/artifact-keeper/security/advisories/new) or the channels in [SECURITY.md](https://github.com/artifact-keeper/artifact-keeper/blob/main/SECURITY.md).
