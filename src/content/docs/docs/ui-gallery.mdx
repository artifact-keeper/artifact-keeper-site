---

The best way to see the Artifact Keeper web interface is the live demo at
**[demo.artifactkeeper.com](https://demo.artifactkeeper.com)**. It runs a current
release, so every page you see there matches what you get when you deploy it yourself.

Areas worth a look on the demo:

- **Core pages:** dashboard, repositories, packages and search
- **Administration:** users, groups, permissions and settings
- **Security:** the security dashboard and [quality gates](/docs/security/quality-gates/)
- **Operations:** analytics, monitoring, [lifecycle policies](/docs/advanced/lifecycle/) and [backups](/docs/advanced/backup/)

To run the same interface locally, follow the [Quickstart](/docs/getting-started/quickstart/).
